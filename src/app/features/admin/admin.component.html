¿De dónde sale esta información? El job consulta la API de Amadeus para las rutas monitoreadas y obtiene el precio actual que ofrecen LATAM, Sky y JetSmart. Con ese precio recién capturado se actualiza la tarifa vigente (tabla tarifa), se registra en el historial de precios (historial_precio) y se recalcula el semáforo comparando contra el promedio de los últimos 30 días.
